# Typing Effects

Animated message input for MoeGram: letters appear with motion, deleted
letters fly away or break into dust, the cursor glides, sent text fades out.

All animation is drawn natively by MoeGram; the plugin only picks settings.

## Settings

- **Insert / Delete / Smooth cursor / Send** — turn each effect on or off
- **Effect style** — Soft, Pop, Bouncy
- **Letters** — Pop, Drop, Zoom, Spin
- **Deleted letters** — Fly away, Dust
- **Curve** — Auto, Smooth, Linear, Cubic, Back, Elastic, Bounce
- **Speed / Intensity**

## Requirements

MoeGram with composer effects API 1 (letter motions, curves and dust).
Desktop only; does not run on exteraGram.
