# moe-plugins

Python plugins for [MoeGram](https://github.com/tenku-png/moegram), a
Telegram Desktop client with a plugin system.

| Plugin | Description |
|---|---|
| [Typing Effects](typing_effects) | Animated message input |

## Install

Copy the plugin's `.py` file into the `plugins` folder of your MoeGram
working directory, then restart MoeGram and enable it in **Settings → Plugins**.
